# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **External visitors**: Farmers, researchers, partners, and the general public seeking information about TARC.
- **Situation**: Browsing from desktop or mobile devices to learn about TARC's research, staff, and services.
- **Job**: Discover research programs, read publications, view staff directory, check events, contact the center.

## Product Purpose

Public-facing website for Tepi Agricultural Research Center that showcases the center's research, staff, publications, news, events, and provides contact information for farmers and partners.

## Positioning

The public face of TARC — a research institution website that communicates agricultural research impact to Ethiopian farming communities and international partners.

## Operating Context

- Hash-based routing (/#/ paths) for static hosting compatibility
- Proxies API calls to localhost:5000
- Runs on localhost:3000 (Vite dev server)
- No authentication required

## Capabilities and Constraints

- Public pages: Home, About, Director, Departments, Staff, Research, Publications, News, Events, Gallery, Contact
- Hero banner with animated topographic contours
- Stats counter section
- Featured research section
- Responsive mobile menu

## Brand Commitments

- Same color palette as dashboard: Deep Forest, Canopy, Fern, Earth, Cream
- Same typography: DM Serif Display + Inter
- Consistent topographic design language

## Evidence on Hand

- Working public app with all pages
- Hash-based routing configured
- API proxy to backend server

## Product Principles

1. Public accessibility — no login required
2. Mobile-first responsive design
3. Clear information architecture for agricultural research content
4. Consistent brand identity with dashboard
